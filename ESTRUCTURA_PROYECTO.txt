┌─────────────────────────────────────────────────────────────────────────────┐
│ 🚀 CÓMO EMPEZAR                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

1. Setup Local (5 min):
   cd backend && pip install -r requirements.txt
   cp .env.example .env  # Editar con claves reales
   uvicorn server:app --reload

   cd frontend && npm install
   cp .env.example .env.local  # Editar con claves
   npm run dev

2. Configurar Stripe (10 min):
   - Crear 3 products en Stripe Dashboard
   - Crear 6 prices (3 monthly + 3 yearly)
   - Copiar price IDs a MongoDB
   - Configurar webhook endpoint

3. Testear (5 min):
   - Abrir http://localhost:5173
   - Click "Hazte Socio" → "Socio Colaborador"
   - Pagar con tarjeta: 4242 4242 4242 4242
   - Verificar dashboard
